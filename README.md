# 有道词典 Ubuntu 兼容修复

> 有道词典 Linux 版（6.0.0）在 Ubuntu 22.04 / 24.04 上装完用不了？
> 启动弹「系统出错」、顶部菜单点了没反应、托盘图标点不动、左侧 dock 还多一个莫名其妙的 python3 齿轮图标？
>
> 这个仓库用几个小脚本就地修好它。**不包含、也不分发有道词典的任何源码或安装包**——脚本只修补你机器上已经安装好的官方版本。

---

## 你的症状对得上吗？

| 你看到的 | 真正的原因 | 对应补丁 |
|---|---|---|
| 一启动就崩，弹出 Ubuntu 的「系统出错 / 检测到问题」 | Python **3.12 删除了 `imp` 模块**（3.11 删了 `inspect.getargspec`，3.10 把 `collections.Mapping` 移走了），而这个 2023 年的包还在用 | `01` |
| 窗口能开，但顶部**词典 / 例句 / 百科 / 翻译**四个菜单**点了没反应** | 后端脚本 `youdao-dict-backend.py` 第 37 行**行首多了一个空格**（包自带的笔误）→ 直接语法错误 → DBus 服务起不来 → 界面每次触碰后端都在主线程**卡 5 秒** | `02` |
| 左侧 dock 里除了词典图标，还多一个叫 **python3 的齿轮图标** | 程序没告诉 Qt 自己的桌面文件名，Qt5 在 Wayland 下就用**进程名**（python3）当窗口标识，GNOME 认不出来 | `03` |
| 顶栏托盘小图标**左键右键都没反应** | `setVisible` 的 Qt 槽签名写错了（复制粘贴错误），JS 调用时 Python 抛异常，而 **JS 侧看不到异常**，于是静默失败 | `04` |
| 在 **Wayland** 会话里偶尔**启动几秒后整个进程消失**（`/var/crash` 里有 SIGSEGV，日志里有 `Xlib.error.BadWindow`） | 窗口还没映射就去写 X 属性（阴影提示），X 服务器回 `BadWindow`；错误从事件回调里逸出，正好撞上第一次 WebKit 绘制 | `05` |
| **缩放窗口不跟手**：抓左上角缩一下，窗口却朝右下角长 | 主窗口是 `QQuickView`，QML 和拖动代码都在调用它**没有的** `setX/setY/move`，Wayland 下两处都静默失败 | `05` |

这四处彼此独立、全都极不起眼——正因为如此，网上流传的教程往往只覆盖其中一条。

## 适用范围

- **系统**：Ubuntu 24.04（Python 3.12）**完全适用**；Ubuntu 22.04（Python 3.10）只需其中一部分补丁，脚本会自动跳过不需要的项
- **应用**：有道词典 Linux 版 **6.0.0**（`youdao-dict_6.0.0-ubuntu-amd64.deb`）
  校验值 sha256：`e56f248c3caf7d0bff9f4f18780d9b258612b490c1c0f332335b8d15471e0dd2`
- 其它 Debian 系发行版理论上同理（补丁按**文件内容**匹配，不按版本号）

> 有道官方**已停止维护 Linux 版**（2024 年前后由官方人员在深度论坛确认），6.0.0 之后没有 6.0.1 / 6.1 / 7.x。所以「等官方更新」这条路不存在，只能打补丁。

## 快速开始

```bash
# 1) 装官方原版（从官网下载，或用你已经下好的 deb）
#    下载页：https://fanyi.youdao.com/download-multi/
#    直链：  https://codown.youdao.com/cidian/linux/youdao-dict_6.0.0-ubuntu-amd64.deb
sudo apt install ./youdao-dict_6.0.0-ubuntu-amd64.deb

# 2) 打补丁
sudo bash install.sh

# 3) 完全退出有道词典，再重新打开（左下角「开始」→ 退出）
```

装完可以随时体检：

```bash
bash verify.sh      # 逐项检查补丁状态，全绿即正常
sudo bash uninstall.sh   # 还原成官方原版
```

每个补丁也可以单独运行（比如你只想修「菜单点不动」）：

```bash
sudo bash payload/02-backend-indent.sh
```

## 脚本会做什么

只改 `/usr/share/youdao-dict/` 下的 **12 个文件**，每个补丁都做到：

- **幂等** —— 已经修过就跳过，重复运行不会出事
- **防呆** —— 目标内容与预期不符（比如官方换了新版本）就**中止**，绝不乱改
- **自动备份** —— 改前存为 `*.bak-<日期>`，与原文件同权限
- **改完校验** —— 用 Python 的 `ast.parse` 做语法检查，失败**自动回滚**

> 补丁按**文件内容**匹配而不是版本号：将来万一官方更新、文件结构变了，脚本会**停下来告诉你**，而不是把文件改坏。

## 已知限制（补丁解决不了）

1. **「百科」搜不到词条、权威词典只剩柯林斯**
   有道服务器已下架这些数据源。实测 2026-09-27：原本 27 个数据源只剩 9 个可用（`ec` / `web_trans` / `ee` / `collins` / `phrs` / `syno` / `blng_sents_part` / `media_sents_part` / `auth_sents_part`），`baike`（百科）、`ec21`（21世纪大英汉）、`ce_new`、`fanyi` 等 18 个已下线。**客户端问得没错，是服务器答「我没有」**，改客户端救不回来。
2. **托盘图标右键菜单弹不出来**
   应用想弹一个 QML 自绘菜单，但 Qt5 的托盘实现（StatusNotifierItem）导出的是 `Menu=/NO_DBUSMENU`——Qt 不实现 DBusMenu，GNOME 侧没有菜单可弹。左键已可用（切换窗口显示/隐藏）。
3. **点窗口右上角的 × 只是隐藏，不是退出**
   这是应用原本的设计（最小化到托盘）。真正退出走**窗口左下角「开始」→ 退出**。想改成点 × 直接退出：软件设置里取消勾选「窗口关闭时最小化到托盘」。
4. **`sudo apt install --reinstall` 或重装 deb 会覆盖回原版** —— 重跑 `install.sh` 即可。
5. **GNOME Wayland 下不能用鼠标拖动窗口**
   Wayland 规定窗口位置由合成器决定，应用只能"请求"。实测（2026-10-25，Ubuntu 24.04 + GNOME 46 + Qt 5.15）：
   - `QWindow.setPosition()` 被**静默忽略**；
   - `startSystemMove()`（应用请合成器代为拖动）在非 tiling 合成器上**直接返回 false**（Qt 5.15 只给 GNOME 的 wayland-extension / wlroots 实现了）。

   补丁 05 把能走的路都走了一遍（Xlib、`setPosition`、`startSystemMove`），**拖动仍无效**；窗口缩放、候选框位置、崩溃问题都已解决。
   想恢复拖动：让有道单独跑在 X11 下——复制 `.desktop` 文件，在 `Exec=` 前加 `env QT_QPA_PLATFORM=xcb`。
   代价是 125% 缩放下文字会略糊（实际像素不变），要不要换由你自己权衡。
6. **左上角拖动缩放不跟手**
   `dae/window.py` 每次鼠标移动都重新判断"当前在哪个角"，抓住左上角缩一下，光标一偏就判成右下角。这是应用自带逻辑（X11 下也一样），补丁未改；右下角是正常的。

## 与其它方案的关系

- **AUR 的 [`youdao-dict`](https://aur.archlinux.org/packages/youdao-dict) 包**（6.0.0-13，2026-02 更新）是目前唯一活跃维护的同类方案，它用的是**和你手上完全相同**的官方 deb（sha256 一致），也独立修了 `imp` → `importlib` 和后端第 37 行的多余空格——**两边的结论互为交叉验证**。
- 它还额外修了我们没有纳入的两处（**按需参考**，本仓库未包含、也未在本机验证）：
  - `window.py` 里 `setX(x)` / `setY(y)` 未取整，某些环境下窗口会跑到屏幕外 → 改成 `int(x)` / `int(y)`
  - `shadowwindow.py` 的合成器判断，去掉 `if not wmHelper.hasComposite:` 一行
- 本仓库比 AUR 多修的部分：**dock 上的 python3 齿轮图标** 与 **托盘点击无反应**。
